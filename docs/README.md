# Better Peacock *for Visual Studio Code*

> Automatically give each Visual Studio Code project, repository, and protected branch a recognizable color.

![Peacock Hero](assets/hero.png)

## Features

- 🎨 **Work More Efficiently** — Quickly identify each of your Visual Studio Code instances using your favorite colors
- 🌐 **Remote Integration** — Color your Visual Studio Code editor uniquely when you are using the remote integration features
- 👥 **Live Share** — Color your Visual Studio Code editor uniquely when you are in a Live Share session as a Guest or a Host

## Quick Start

1. Package Better Peacock with `npm run package` and install the generated VSIX
2. Open the command palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)
3. Type **Better Peacock: Change to a favorite color**
4. Pick a color and enjoy!
